# Skills

A collection of custom skills for AI coding agents and other workflows.

Each skill provides instructions for completing a specific task, including how to approach the work, what to check, and how to handle common edge cases.

## Skills

### Resume Tailor

Tailors an existing resume to a specific job posting.

- Reads the job description and identifies its main requirements.
- Compares the posting with the user's existing resume.
- Asks the user to confirm relevant skills or experience before adding them.
- Rewrites resume content to better reflect the user's actual qualifications.
- Preserves the original resume's formatting as closely as possible.
- Generates a tailored PDF and provides before-and-after match ratings out of 10.

The skill is designed to improve how relevant experience is presented without inventing qualifications or making unsupported claims.

*More skills will be added as they are developed.*

## Adding Skills

Each skill has its own directory containing a `SKILL.md` file. Some skills may also include supporting files, scripts, or reference materials.

## Contributing

When adding or updating a skill:

- Keep instructions clear and specific.
- Explain when the skill should be used.
- Include steps for handling common edge cases.
- Avoid repeating instructions unnecessarily.
- Test the skill before committing changes.
